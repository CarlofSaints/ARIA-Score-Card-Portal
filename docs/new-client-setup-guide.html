Setting up a new client

A new client takes about 30 minutes. No new SQL work is needed if the client already exists in SQL and sells only in PnP, SPAR, Builders, Game, Makro or Shoprite Checkers.

1Create the client ARIA admin

Only an ARIA admin can create a client, because this step decides whose data the portal can see. KAM: send your ARIA admin everything from the table above.

  1. Sign in to the ARIA admin area.
  2. Click New Client.
  3. Under Client Details:
    • Type the Client Name. The Slug fills itself in.
    • In Custom Domains, type the web address.
    • In SQL Server Client, pick the client. This one field links the portal to its data. Never leave it on "No SQL mapping".
  4. Under Branding, enter the Primary Colour, the other colours if they have them, then Choose File for the logo.
  5. Under Modules, untick anything the client hasn't paid for.
  6. Under KPI Weightings, move the sliders until the total says 100 / 100 in green.
  7. Under Initial Admin User, enter the KAM's name, email and a temporary password. Leave both boxes ticked.
  8. Click Create Client.
  9. Your ARIA admin switches on the web address. The portal won't open at its address until this is done.

The KAM gets a welcome email with their login.

2Load the data KAM

No data shows until the first sync has run. You never pick SQL queries: the portal runs the same ones for every client, filtered by the client name chosen in Step 1.

  1. Open the welcome email, sign in at the client's web address and set your own password.
  2. In the left menu, click Control Centre.
  3. Click Sync All and wait for it to finish. Sales alone can take about 2 minutes. Don't close the tab.
  4. Read the result under the buttons. Each part shows how many rows it pulled. If a part failed, send that line to your ARIA admin.
  5. Optional, for last year's sales: under What to sync, tick Full months (LY) backfill, then click Sync Now. Each run pulls 2 months. When it says "run again to continue", click Sync Now again.
  6. Set the auto-sync: under Add a time, pick an hour (SA time) and click + Add. Add as many as you want, then click Save Schedule.
With no times saved, the data only updates when someone clicks Sync Now.

3Add the users KAM

Give every KAM the KAM role. Only KAM users can be picked in Step 4.

  1. In the left menu, click Admin, then + New User.
  2. Fill in Name, Email, a temporary Password and the Role.
  3. Leave Send welcome email with credentials ticked and click Create User.

The Admin login isn't a KAM, so it can't have its own KAM scorecard. If the KAM running the client also needs one, add them again with the KAM role, using a different email address.

4KAM Mapping KAM

This tells the portal which chains and brands belong to each KAM. It drives the KAM scorecard and the KAM filter on every page. Do it after Step 2: the chain and brand lists come from the first sync.

  1. In the left menu, click KAM Mapping, then + Add Mapping.
  2. In KAM, pick the KAM.
  3. Tick their Channels (chains) and Brands, then click Save Mapping.
  4. Repeat for each KAM.

5Check it worked KAM

Open Sales, Out of Stocks, Numerical Distribution and Phantom Stock. Each should show rows for the client. Then open a scorecard and pick a KAM from the filter.
